# sounio-tmlanguage

TextMate grammar for the [Sounio](https://github.com/Sounio-lang/sounio) programming language — <https://souniolang.org>.

- Scope name: `source.sounio`
- File extension: `.sio`
- Grammar: [`grammars/sounio.tmLanguage.json`](grammars/sounio.tmLanguage.json)

## Usage

**VS Code** — in an extension `package.json`:

```json
"contributes": {
  "languages": [{ "id": "sounio", "extensions": [".sio"] }],
  "grammars": [{ "language": "sounio", "scopeName": "source.sounio", "path": "./grammars/sounio.tmLanguage.json" }]
}
```

**Shiki**:

```js
import sounio from './grammars/sounio.tmLanguage.json' with { type: 'json' };
const highlighter = await createHighlighter({ langs: [{ ...sounio, name: 'sounio' }], themes: ['github-dark'] });
```

**GitHub Linguist** — this repository is intended to be referenced as a grammar submodule providing `source.sounio`.

## Development

The grammar is generated by `scripts/gen.py` (`python3 scripts/gen.py` writes `grammars/sounio.tmLanguage.json`).

```sh
npm install
npm test
```

Tests tokenize the fixtures in `test/fixtures/` with `vscode-textmate` + `vscode-oniguruma`.
